# AUTH-BFF-008 동시 BFF refresh는 동일 저장 행 잠금으로 직렬화한다

## 인수 문장 및 근거

동시 BFF refresh는 동일 저장 행 잠금으로 직렬화한다.
근거: docs/contract/v0.2.1.md의 사용자 승인 브라우저 인증 B안 및 인증 세션 정책. upstream HTTP 성공/오류 형식은 docs/contract/openapi.yaml.

## 요청 / 재현

만료 access와 유효 refresh를 가진 동일 쿠키로 서로 다른 BFF 인스턴스의 보호 중계 2개를 barrier에서 동시에 시작한다. 트랜잭션/잠금 및 upstream refresh 사용 기록을 관찰한다.

## 기대 HTTP와 저장 상태

행 잠금 획득 후 최신 토큰을 재조회한다. 뒤 요청은 이미 회전된 원문을 다시 보내지 않는다. 두 요청은 유효 세션으로 성공하고 재사용 감지 때문에 폐기되지 않는다. 갱신 저장은 원자적이다.

## 변하지 않아야 하는 필드

다른 web_sessions 행 및 최초 절대 만료 불변. 실패한 트랜잭션은 부분 토큰 갱신 금지.

## 결과: 미실행

인수 규격만 작성. DB 설치/실행/접속 없음. mock 또는 정적 검토로 실제 DB/HTTP/브라우저 인수 통과를 주장하지 않는다.
