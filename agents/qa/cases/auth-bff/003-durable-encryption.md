# AUTH-BFF-003 BFF 토큰은 PostgreSQL에 AES-256-GCM 인증 암호화로 저장한다

## 인수 문장 및 근거

BFF 토큰은 PostgreSQL에 AES-256-GCM 인증 암호화로 저장한다.
근거: docs/contract/v0.2.1.md의 사용자 승인 브라우저 인증 B안 및 인증 세션 정책. upstream HTTP 성공/오류 형식은 docs/contract/openapi.yaml.

## 요청 / 재현

로그인 후 web_sessions 저장 값과 구성 검증을 관찰한다. 환경 암호화 키가 없을 때 실행을 시도하고 암호문의 인증 태그/내용을 변조한 상태에서 복구를 요청한다.

## 기대 HTTP와 저장 상태

세션 식별자는 해시 조회. 토큰 원문은 환경 키의 AES-256-GCM으로 복구 가능한 암호문으로 저장. 키 누락은 실행 실패이며 메모리 대체 금지. 변조는 인증 복호화 실패 및 접근 거절; 구체 HTTP code는 계약 미정이므로 고정하지 않는다.

## 변하지 않아야 하는 필드

실패 시 토큰을 원문 저장하거나 변조된 값을 정상 토큰으로 사용하지 않는다. 다른 세션은 불변.

## 결과: 미실행

인수 규격만 작성. DB 설치/실행/접속 없음. mock 또는 정적 검토로 실제 DB/HTTP/브라우저 인수 통과를 주장하지 않는다.
